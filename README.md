## Features
- Donate unused items easily
- Connects donors with NGOs
- Simple and user-friendly interface
- Secure form handling

## Tech Stack
- HTML
- CSS
- JavaScript
- Python
- Django
- SQLite

## Purpose
This project aims to promote social responsibility by encouraging people to donate instead of dumping usable items.
# Don-t-Dump-Donate-E-Donation
Don’t Dump – Donate is a Django-based e-donation platform that connects donors with NGOs and people in need, encouraging responsible reuse of items and reducing waste through technology.
